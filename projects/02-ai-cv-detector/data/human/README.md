# Human CVs

Download the **Resume Dataset** from Kaggle (search "Resume Dataset snehaanbhawal", or any resume CSV collected before ChatGPT's release in late 2022) and put `Resume.csv` in this folder.

The CSV needs a text column (`Resume_str`, `Resume` or `text`). `ID` and `Category` columns are used if present.

It's git-ignored: don't re-publish the dataset. Link to it instead.
